# 🏋️ Gym Website

A full-stack gym management website built as my first web development project. The website provides information about the gym, showcases available training programs, and allows users to submit membership details through an online registration form. User data is stored securely in MongoDB, demonstrating basic backend integration with a database.

This project was created to strengthen my understanding of full-stack web development by combining frontend design, backend development, and database connectivity.

---

## Features

* Responsive and user-friendly interface
* Home page with gym information
* Training programs and membership details
* Online registration form
* MongoDB database integration for storing user information
* Clean navigation between pages
* Organized project structure for easy maintenance

## Getting Started

### Prerequisites

* Node.js
* npm
* MongoDB

### Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/gym-website.git
```

2. Open the project folder.

```bash
cd gym-website
```

3. Install the required dependencies.

```bash
npm install
```

4. Configure your MongoDB connection.

5. Start the server.

```bash
node server.js
```

6. Open your browser and visit:

```
http://localhost:3000
```
